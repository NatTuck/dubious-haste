# TTRPG MVP Specifications

A tabletop RPG MVP needs these core components:

## 1. Resolution System

Our game is going to be about virtual reality simulations (we are in a
simulation, as are almost all other sentient beings, those simulations nest,
quantum mechanics is an Optimization, but a human mind can be simulated with
much heavier optimization). So the mechanics are intentionally built so they'll
run on a computer and they look like they're simulating a computer simulation.

Actions that can fail are resolved with a trait test.

## 2. Character Mechanics

Characters have traits, which unify attributes, skills, and maybe other stuff.



## 3. Character Creation

- How players build characters

## 4. Combat/Conflict

- How fights and challenges resolve

## 5. Progression

- XP, leveling, or advancement

## 6. Core Setting

- World lore and tone (minimal)

---

## For LLM Benchmarking: Key Variation Points

To make rule sets meaningfully distinct for differentiating training memory from context, vary:

| Element | Variation Options |
|---------|-------------------|
| Dice systems | d20, d6 pool, d100, 2d6, custom |
| Attribute distributions | 3d6, 4d6 drop lowest, point-buy, rolling |
| Resolution math | Target numbers, degrees of success, Advantage/Disadvantage, open-ended |
| Thematic vocabulary | High fantasy, sci-fi, horror, modern, post-apocalyptic |
| Progression curves | Flat, exponential, milestone-based |
| Success thresholds | Fixed DC, opposed rolls, variable band ranges |
